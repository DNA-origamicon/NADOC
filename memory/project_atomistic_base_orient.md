The oxDNA-relaxed **atomistic display** reconstruction had a systematic base-tilt artifact that read as "A-form / RNA, not B-form." Diagnosed + fixed 2026-07-23.

**Diagnosis (all cross-validated, incl. against the 1ZEW crystal + the ideal `build_atomistic_model`).** The reconstruction IS B-form: rise 3.34 Å, twist ~34°, C2′-endo pucker (P≈154° vs 1ZEW 166°), natural D-sugar chirality, WC C1′–C1′ ~10.5 Å, solid core — NOT A-form, NOT RNA. The only non-B signal was base-pair **inclination**. Root cause: `cg_to_atomistic.deformed_helix_axes` builds its centerline tangent from the midpoint of the two paired backbone sites, which spiral ~208° apart (not 180°); after smoothing that tangent sits **~12° off the true helix axis even for a perfectly straight, unrelaxed duplex**. The placer uses that tangent as the base slab normal `e_z`, injecting ~5–6° of excess base tilt (measured 15.7° vs the validated ideal-build's 10.0° on a straight duplex → A-form range). oxDNA's own **a3** is exactly on-axis (0° on the ideal duplex) → a3 is the correct reference.

**Why not the full a1/a3 rigid stamp (the 2026-06-21 reverted attempt).** Stamping each base to its OWN a3 collapses WC pairs (C1′–C1′ 0.48 vs 0.94 nm) because FWD/REV a3 are only ~157° apart (real propeller). The fix uses the pair's **SHARED** stacking axis `normalize(a3_fwd − a3_rev)` for `e_z` only, keeping the radial/position machinery → pairing preserved (0.96 nm) AND orientation restored to ideal-build.

**The switch.** `deformed_helix_axes(..., base_orient=...)`: `"design_axis"` (legacy off-axis tangent) vs `"oxdna_a3"` (shared-a3). Threaded through `_frame_atomistic_overrides` → `build_display_model` (oxdna_health.py), whose default = module const `_DISPLAY_BASE_ORIENT = os.environ.get("NADOC_ATOMISTIC_BASE_ORIENT", "oxdna_a3")`. So DISPLAY defaults ON; revert with `NADOC_ATOMISTIC_BASE_ORIENT=design_axis` + server restart.

**OPENING error = same artifact; also fixed (2026-07-24).** The design-axis tangent doesn't just tilt the base plane — it rotates WC pairs OPEN. Proven on a real oxDNA-run duplex (clean seated duplex + VoltronCore, measuring primary WC H-bond with the CORRECT designed (h,bp) pairing — the reliable oracle): `design_axis` → H-bond 4.12 Å open (straight duplex) / 2.99 Å, 55–68% closed (VoltronCore); `oxdna_a3` → **2.89 Å canonical / 2.85 Å, 77% closed**. So the a3 default ALREADY fixes opening for display+export. **Earlier "still open" readings (4.4 Å, barnaba σ ≈ −42°) were MEASUREMENT ARTIFACTS** — nearest-C1′ mispairing + barnaba `annotate` spurious stacking pairs. barnaba (installed in venv) computes eRMSD/G-vectors, NOT 3DNA base-pair params; hand-rolling σ from its frames never validated on the 16k origami. **Trust WC H-bond closure with designed pairing, not σ.**

**NAMD seed NOW fixed too (2026-07-24, `build_atomistic_model_from_cg_spline` in cg_to_atomistic.py:~301).** Added `base_orient="oxdna_a3"` AND `relaxed_oxdna_phase=True` to its `deformed_helix_axes`/`build_atomistic_model` calls. BOTH needed on designs with REVERSE helices: a3 alone → 3.08 Å, +relaxed_phase (uniform FWD azimuthal, the relaxed-structure convention) → 2.85 Å canonical on VoltronCore (seated seed / conf.dat). Real LJ clashes NOT worsened (6 vs 8 old, excluding 1-2/1-3 neighbors — the naïve "42 vs 8" was O3′↔OP2 angle-neighbors, not real clashes). **VALIDATED in a test-dedicated session (user ran the heavy suite, one failure resolved) — the a3 seed is safe for NAMD.** Nuance: on a FULLY-relaxed production conf (last_conf.dat) both seeds close ~equally (2.95 vs 2.96) — the a3 closure win is largest on seated/ideal geometry; on relaxed structures it's marginal.

**Sanity-check tool: `scripts/namd_seed_sanity.py`** (built 2026-07-24). Fast GEOMETRY pre-check of the seed — builds it both ways (design_axis vs oxdna_a3), gates on WC **closure** (primary H-bond ≤ 3.1 Å = the reliable, tool-free NAMD-readiness proxy), reports base-ring clashes for reference. `python scripts/namd_seed_sanity.py [job_id]`. Why NOT a real NAMD run: the seed is heavy-atom-only; a meaningful NAMD energy needs psfgen H-build (`namd_solvate.build_charmm_psfgen_topology`, strict) which isn't always installed — without H the vacuum VDW is non-physical (both seeds "spike" ~1e10). Total heavy-atom clash counts are ALSO unreliable (dominated by fast-bridge O3′-P linker geometry) → gate on closure + base-only clashes, not total. Real NAMD startup = test-session's job.

**Wide-export gotcha (not a bug).** `write_configuration` builds duplexes ~2× too wide by default (CM-CM 19.3 Å, base-site 12.5 Å = `design_ref.dat`); pass `oxdna_native_seed=True` to seat pairs at oxDNA native width (base-site 3.7 Å, 100% paired = the `conf.dat` seed). A bare oxDNA MD on the wide export melts the duplex; real jobs use native-seed + mutual-trap relaxation. To run oxDNA manually: seat + traps + MD.

**Coverage (why it's automatic).** Both **oxDNA Display** (relaxed orientation = per-frame `(origin,R)` from `display_frames_payload`→`build_display_model`) and **oxDNA-job PDB/DCD trajectory export** (`iter_composite_trajectory_atomistic`→`frame_atomistic_flat`→`build_display_model`) flow through `build_display_model` → auto-corrected, no disk-cache rebuild needed (the disk `atomistic_display_bundle.json` holds only orientation-independent topology/bonds/`atom_local`; orientation lives in the live R matrices). Design-level `/design/export/pdb` + `/design/atomistic` use the ideal `build_atomistic_model(design)` (already correct 10° placement) — unaffected. NAMD **seed** (`build_atomistic_model_from_cg_spline`) unchanged.

**Magnitude / open item.** Improvement is real but MODEST — base-ring normal vs oxDNA a3 (faithfulness): clean non-E-field job median 13.6°→11.2°, strained E-field job 11.8°→11.0°. The ~11° floor = B-form template base tilt + real propeller (irreducible). Effect is clearest on **non-E-field jobs** (real strain masks it on E-field runs). **OPEN: user visual acceptance in-app on a clean job not yet done** (the actual acceptance test). If it under-delivers visually, the residual is template/propeller, not this tangent.
