# NADOC benchmarks

The [desktop benchmark map](desktop/README.md) consolidates front- and backend operation coverage, current CPU measurements, historical evidence, reproduction commands and the remaining desktop measurement backlog. Start there for optimization planning.

The existing feature-evaluation and scrubbing JSON files in this directory remain historical evidence; they are linked from the desktop workflow matrix where relevant. Native VR benchmarks are documented separately in [native/vr_viewer/benchmarks](../../native/vr_viewer/benchmarks/README.md).
