# Streptavidin–biotin–DNA atomistic preparation for NAMD

The new preparation workflow exports the protein, ligand and DNA components in
their authored common coordinate frame, with explicit atom identity and a
phosphate-preserving psfgen recipe. **The full complex is not simulation-ready:**
the normal export path does not yet carry a production-qualified ligand–DNA
parameter package. An [isolated BTE/BTE5 candidate](biotin_dna_junction.md) now
passes native topology checks and a 20 ps GPU-resident NAMD check. No dummy parameters or oxDNA springs are used
as substitutes. The normal coated-particle NAMD export guards remain in place.

## Chemistry and mapping

- Streptavidin uses the complete four-chain biological tetramer from the bundled
  [1STP structure](https://www.rcsb.org/structure/1STP). Each resolved chain spans
  residues 13–133 without an internal sequence gap. NTER/CTER patches terminate
  this resolved construct; unresolved terminal tails are not silently rebuilt.
- Bound D-biotin retains its crystallographic ring stereochemistry and pocket
  registration. [RCSB BTN](https://www.rcsb.org/ligand/BTN) supplies the reference
  chemical identity. Protein–biotin binding is noncovalent: no protein–ligand
  covalent bond or coarse spring is added.
- The existing [IDT 5′ Biotin-TEG structure](https://www.idtdna.com/site/Catalog/Modifications/GetStructureImage/2100)
  defines the spacer graph. The added fragment has 28 heavy atoms, 29 internal
  heavy-atom bonds (two ring closures), two carbonyl double bonds and 32 attached
  hydrogens by valence. The chemical definition records those hydrogen counts;
  ligand hydrogen coordinates are not yet generated by a qualified topology.
- Linker O4T bonds to the existing DNA 5′ P. The usual CHARMM `5TER` patch deletes
  P/O1P/O2P and must not be used on this modified terminus. The recipe uses
  `first NONE`, deoxyribose patch `DEOX`, and requires a dedicated two-residue
  `BTE5` boundary patch. That patch must define the chemically appropriate charge
  redistribution, atom types and all cross-boundary terms, not just a bond.
- DNA, protein monomers and ligands receive distinct four-character segment IDs.
  Mapping uses `(segid, resid, atom_name)` and resolves final 1-based PSF atom IDs
  after hydrogen insertion. Protein aliases are handled explicitly. Input PDB
  serials are never assumed to be final PSF indices.

The separate gold-free package includes all design DNA and all four monomers of
each DNA-occupied tetramer. Gold and unoccupied coating tetramers are outside this
package's scope; omitted core IDs are recorded. Coating poses are used only as
initial coordinates. Source designs and DNA geometry are not modified.

Disconnected display fits, missing strand/pocket owners, duplicate pocket or
terminal assignments, and unresolved internal protein sequence gaps are rejected.
Heavy-atom PDB output includes ligand and phosphate CONECT records, but these are
connectivity evidence, not force-field parameters or a minimized conformation.

## Use and retained evidence

```bash
.venv/bin/python scripts/prepare_strep_biotin_namd.py source.nadoc --output experiments/strep_biotin_namd/ws/review_new
.venv/bin/python -m experiments.strep_biotin_namd.validate_preparation --output experiments/strep_biotin_namd/ws/check_new
```

Output directories must be new. `mapping.json` states `simulation_ready: false`
and names the missing force-field pieces. `chemical_definition.json` records
the graph and DNA boundary; `inputs/` contains distinct component PDBs.
`build_psfgen.tcl` requires `biotin_teg.rtf` defining `BTE` and `BTE5`; it is a
preparation recipe, not a complete NAMD run package. No launch configuration is
emitted while parameters are unresolved.

Native psfgen validation of the **protein portion only** produced 6,976 atoms,
including 3,368 hydrogens and four newly completed terminal oxygens. All 3,604
source protein heavy atoms mapped uniquely. Its 7,064 bonds, 12,576 angles,
18,420 dihedrals and 476 CMAP terms resolved against the bundled CHARMM36m
parameters; total protein charge was −8 e for the declared terminal/protonation
convention. This validates protein topology construction, not ligand parameters,
solvated dynamics or binding affinity.

The compact [validation record](validation/strep_biotin_namd_2026-09-16.json)
retains measurements and hashes. Raw final inputs and protein PSF/PDB evidence
are isolated in `experiments/strep_biotin_namd/ws/preparation_final/`.

## Public parameter-source audit and remaining work

The [MacKerell CHARMM distribution](https://mackerell.umaryland.edu/charmm_ff.shtml)
provides CHARMM36m and CGenFF 5.0 in its February 2026 release. The downloaded
archive was inspected; no ready Biotin-TEG–DNA residue/boundary package was found.
The CGenFF reference library is not itself a parameter assignment for this molecule.
This is a local-library limitation, not an absence of published models. The
[literature audit](strep_biotin_parameter_literature.md) identifies published
NAMD biotin–linker–DNA patches (Comer et al., 2012) and CGenFF biotin/PEG
parameterization (Sedlak et al., 2020). Their raw assignments and exact chemical
match to our Biotin-TEG–DNA boundary have not yet been verified.
Its [program documentation](https://mackerell.umaryland.edu/cgenff_prgrm.php)
describes molecule-specific parameter assignment and validation.

The experimental BTE/BTE5 package now includes all hydrogens, charges, supplied
ligand impropers and mixed phosphodiester terms with source provenance. The
full PSF charge, phosphate valence and parameter coverage pass, followed by
explicit-solvent GPU NAMD minimization and 20 ps of dynamics. Longer junction
conformational and ring/pocket energetic qualification remain; production
export is not enabled. Streptavidin–gold chemistry remains outside this work.

## Prepared parameterization inputs

The [research workflow](../experiments/strep_biotin_namd/README.md) now packages
unchanged protein/DNA force fields and CGenFF reference compounds, with hashes.
It generates an explicit-hydrogen, stereochemistry-preserving Biotin-TEG
methyl-capped phosphodiester model for CGenFF, atom ownership, cross-boundary
term inventory and named QM scan targets. The full ligand-specific literature
assignments have not been recovered. The user supplied a new CGenFF assignment
for the exact capped input; its graph, charge and parameter coverage pass.
[Assignment evidence](validation/biotin_cgenff_assignment_2026-09-16.json) records
the hash and results. It uses program 4.0/library 5.0, with maximum bonded/charge
penalties 26/16.547. Preserve this seed and prioritize biotin ring/pocket checks
and longer DNA-sugar boundary qualification. The new candidate is an experimental
simulation path; it does not enable the normal application export.
