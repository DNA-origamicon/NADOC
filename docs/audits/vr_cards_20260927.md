# Collapsible desktop cards in VR

The sidebar generator now extracts titled desktop panel sections, nested ox-cards,
fieldset legends and details summaries after the existing right-tab relocation
and canonical simulation-card ordering. It emits stable card IDs and ancestor
lists. Equal titles such as Advanced under different engine cards remain distinct.
Explicit dynamic control templates attach to their corresponding desktop card,
or to a source-linked template group where no static header exists. The resulting
inventory contains 91 section titles and the existing 851 mapped controls/options.

Selecting a title through either pointer/trigger or trackpad-focus/trigger toggles
that card. Section titles remain enabled even if all children are unavailable.
Collapsed descendants are excluded from rendering, hit testing and exported/focus
controls. Visible counts and scrollbar size/range update immediately. The toggled
title remains on screen and retains focus, including at the end of a long list.
Nested state is independent, remembered across tab/menu changes for the viewer
session; cards start expanded. +/- indicators and Expand/Collapse Card captions
make the action explicit. The mirrored scrollbar placement is preserved.

Validation completed before the final live runs:

- Native CTest 37/37: all expanded layouts, every card's descendant filtering,
  title activation despite disabled contents, focused title retention, collapse
  layouts and independent nested state across tab/menu changes.
- Node hierarchy extraction test passed: repeated titles, nested details, ancestor
  membership, and controls outside cards.
- Catalog drift check and Python lint passed.
- Initial `steady_fast` physical-runtime ScryWrite test passed on both hands using
  both input routes. Collapsed and expanded captures pass the stereo pixel oracle;
  the collapsed capture was visually inspected. Desktop verification also passed.

Evidence is retained under `.development-artifacts/vr-cards/`. Physical headset
legibility and preference for starting expanded remain manual review items.

Final focus validation passed all four unchanged controller profiles using the
new desktop card order. Both hands passed both collapse/expand input routes;
steady profiles acquired every title on the first reach, while each variable
profile used one extra title reach. All retries remain recorded. The final actual
X11 desktop check matched at 100%. See `.development-artifacts/vr-cards/validated`.

The complete `steady_fast` catalog tour passed all 122 pages / 942 entries
(851 mapped controls plus 91 card titles), with stereo pixel checks on every page
and 100% final desktop agreement. Evidence: `.development-artifacts/vr-cards/full-catalog`.
All three owned test viewers and their temporary sockets were cleaned up.
