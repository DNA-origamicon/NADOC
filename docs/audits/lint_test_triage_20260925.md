## Remaining failure

Reproduce with:

```sh
just test-affected tests/test_geometry.py::test_the_scalar_and_loop_skip_fast_paths_agree
```

For the first failing fixture (forward helix, non-compacted skip at bp 5),
backbone positions, axis points/tangents, radial directions and azimuths are
identical. One base-position component and six base-normal components differ
by at most `1.1102230246251565e-16` (positions in nm, normals dimensionless).

The scalar calculation in `backend/core/geometry.py` uses
`np.linalg.norm(base_pair_vec)`, whose installed NumPy implementation computes
`sqrt(x.dot(x))`. The vector path uses `np.linalg.norm(..., axis=1)`, computing
`sqrt(add.reduce(x*x, axis=1))`. Their norms differ by
`2.220446049250313e-16` at two rows of this fixture. The test requires exact
equality, so this discrepancy is sufficient to fail it.

Neither production calculation nor the strict assertion was changed. The
[geometry authorization rule](../../memory/feedback_geometry_change_authorization.md)
requires an isolated, inspectable A/B candidate and explicit authorization
before changing production molecular placement. No candidate is promoted and
no geometry golden is regenerated by this repair.
