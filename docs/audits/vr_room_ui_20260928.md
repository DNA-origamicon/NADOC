# Frosted VR menus and calibrated floor — 2026-09-28

## Implementation

`frosted_glass.hpp` captures a half-resolution scene backdrop separately for each
observer view, generates mipmaps and applies a weighted blur beneath sharp menu
foregrounds. It is shared by sidebar/detailed menu surfaces and the view-tools
panel. `room_floor.hpp` draws a non-pickable, fading grid and calibrated rectangular
play-area outline using OpenXR STAGE. Main renderer changes are thin integration.
The room's actual bounds were 3.1 × 2.6 m. Existing simulation work and unrelated
working-tree changes were retained; the known CanDo expansion bug is unchanged.
