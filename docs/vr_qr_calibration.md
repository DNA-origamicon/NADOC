# Retired QR spatial alignment tools

Removed on 2026-10-16: Vive QR camera calibration, printable calibration cubes, mobile QR pose tracking, and reference-marker sheets. Their menu actions, runtime workers, render hooks, exporters, and dedicated tests have been removed.

[Guest QR invitations](meeting_room_target.md) remain supported. Use the VR **Share** tab to start or end a presentation; guests join with the same reusable invitation.
